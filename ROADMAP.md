# Roadmap

What is planned next. Done items move to [CHANGELOG.md](CHANGELOG.md).

## Next

- [ ] **Better mixed packing.** With many distinct box sizes the planner can end up one
  pallet above what careful manual loading achieves (for example 5 stackable pallets where
  4 are possible). Real shipments that show the gap become regression tests.
- [ ] **Parallel search.** The strategies and modes are independent and could run in
  parallel processes for very varied shipments.

## Later

- [ ] More bundled profiles (other marketplaces and regions), contributed with sources.
- [ ] Optional time budget for the search.
- [ ] Double-stacked pallet totals (such as Walmart's 108 in) and overhang.
